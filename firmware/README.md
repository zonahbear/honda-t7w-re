# firmware/

Original firmware and update files go here. **Nothing in this directory is committed** (see `.gitignore`).

Rules:

1. Treat every file as untrusted. Never execute it, never flash it.
2. Never modify an original. Unpack into `analysis/<sha256-prefix>/` with `tools/extract_firmware.py`.
3. Record every file in the table below (and in `docs/firmware.md`) before analyzing it.
